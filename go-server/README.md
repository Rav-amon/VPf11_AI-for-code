# HTTP API пользователей на Go

Это перенос сервера из `api.py`. Маршруты, коды ответов и формат JSON сохранены. Библиотека `utils.py` сюда не входит: пароли и теги остаются в Python-модуле.

Сервер слушает только `http://127.0.0.1:5000`. База — файл SQLite. Список активных id хранится в памяти процесса и очищается при остановке.

## Требования

- Go 1.26 или новее. Проверено на Go 1.27.
- Компилятор C не нужен: SQLite подключается чистым Go-драйвером `modernc.org/sqlite`.

Если команда `go version` не находится, установите Go с [https://go.dev/dl/](https://go.dev/dl/) и откройте новый терминал.

## Запуск

Из каталога `go-server`:

```powershell
cd go-server
go run .
```

При первом запуске Go скачает зависимости и создаст `go.sum`. В текущем каталоге появится файл `test.db`.

Остановка сервера: `Ctrl+C`.

Другой файл базы задаётся переменной `API_DB_PATH`:

```powershell
$env:API_DB_PATH = "C:\data\api.db"
go run .
```

Каталог для файла базы должен уже существовать. Если порт 5000 занят Python-сервером из `api.py`, остановите его перед запуском.

Сборка отдельного файла:

```powershell
go build -o users-api.exe .
.\users-api.exe
```

Проверка поведения без запуска сервера:

```powershell
go test
```

## Формат ответа

Успех:

```json
{
  "data": {},
  "error": null,
  "message": "Пользователь создан"
}
```

Ошибка:

```json
{
  "data": null,
  "error": {
    "code": "user_not_found",
    "message": "Пользователь не найден",
    "details": {}
  },
  "message": "Пользователь не найден"
}
```

Имя обрезается по краям. Пустое имя и имя длиннее 200 символов отклоняются. Длина считается в символах, не в байтах. Одинаковые имена можно сохранять несколько раз.

Тело `POST` должно быть JSON-объектом с заголовком `Content-Type: application/json`. Размер тела ограничен 1 МБ.

## Маршруты

### Создать пользователя

`POST /api/v1/users`

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri http://127.0.0.1:5000/api/v1/users `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"name":"Анна"}'
```

Ответ `201`:

```json
{
  "data": { "id": 1 },
  "error": null,
  "message": "Пользователь создан"
}
```

Нет заголовка JSON или тело не объект — `400`, код `invalid_body`. Имя не строка, пустое или слишком длинное — `400`, код `invalid_name`.

### Прочитать пользователя

`GET /api/v1/users/<id>`

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:5000/api/v1/users/1
```

Ответ `200`:

```json
{
  "data": { "id": 1, "name": "Анна" },
  "error": null,
  "message": "Пользователь найден"
}
```

Нет записи — `404`, код `user_not_found`. Id меньше 1 — `400`, код `invalid_user_id`. Если сегмент пути не является целым числом, маршрут не совпадает и ответ `404` с кодом `not_found`.

### Отметить активным

`POST /api/v1/users/<id>/active`

Пользователь должен уже существовать. В памяти остаётся не больше 5 последних id. Шестая отметка вытесняет самую старую. Один id может повторяться.

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri http://127.0.0.1:5000/api/v1/users/1/active
```

Ответ `200`:

```json
{
  "data": { "active_user_ids": [1] },
  "error": null,
  "message": "Пользователь отмечен активным"
}
```

### Список активных

`GET /api/v1/active-users`

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:5000/api/v1/active-users
```

Ответ `200`:

```json
{
  "data": { "active_user_ids": [1] },
  "error": null,
  "message": "Список активных пользователей получен"
}
```

## Коды ошибок

| Код | Статус | Когда возникает |
| --- | --- | --- |
| `invalid_body` | 400 | Тело не JSON-объект, неверный тип содержимого или тело больше 1 МБ |
| `invalid_name` | 400 | Имя пустое, длиннее 200 символов или не строка |
| `invalid_user_id` | 400 | Id меньше 1 |
| `user_not_found` | 404 | Пользователь с таким id не найден |
| `not_found` | 404 | Маршрут не найден |
| `method_not_allowed` | 405 | Метод не поддерживается этим маршрутом |
| `database_error` | 500 | Сбой SQLite |
| `internal_error` | 500 | Непредвиденная ошибка сервера |

Клиенту не отдаются текст SQL и внутренние исключения. Техническая причина пишется в журнал процесса.

## Хранение

Таблица создаётся при старте:

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL
);
```

Имя передаётся в запрос параметром, а не склейкой строки. Запись в базу сериализована одним соединением. Список активных id защищён отдельной блокировкой.

Файл `test.db` этого сервера не связан с `test.db` Python-сервера, если запускать Go-сервер из каталога `go-server`. Переменная `API_DB_PATH` указывает на конкретный файл, если базы нужно развести явно.
